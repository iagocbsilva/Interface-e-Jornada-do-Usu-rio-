# Interface e Jornada do Utilizador (UI/UX) - Finance Management Mobile App

Documentação e apresentação do projeto de design de interface e experiência do utilizador desenvolvido para a aplicação móvel de gestão financeira.

---

## Visão Geral do Projeto

Este projeto foca-se na conceção de uma experiência fluida, intuitiva e acessível para a gestão de finanças pessoais. O trabalho abrangeu todo o planeamento de fluxos, estruturação de componentes e prototipagem interativa no Figma.

---

## Principais Recursos e Componentes

- **Design System Consistente**: Aplicação de estilos globais (paleta de cores, tipografia e espaçamentos) para garantir um padrão visual coeso.
- **Componentização Avançada**: Criação de elementos reutilizáveis para otimizar a consistência e a escalabilidade da interface.
- **Prototipagem Interativa**: Simulação de fluxos de navegação e micro-interações sem código, permitindo validar a jornada do utilizador de ponta a ponta.
- **Colaboração e Iteração**: Metodologia ágil aplicada no desenho de ecrãs adaptados aos fluxos de orçamento e controlo financeiro.

---

## Metodologia de UX/UI

- **Foco na Usabilidade**: Redução de fricção nas tarefas principais do utilizador (como registo de despesas e acompanhamento de saldos).
- **Hierarquia Visual**: Organização clara de conteúdos para facilitar a leitura rápida em dispositivos móveis.
